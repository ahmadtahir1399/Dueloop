# Environment reference

GENERATED by `pnpm env:example` from `packages/config/src/env.ts`; do not edit by hand. Secret values never go in a
file that is committed, a log line, an image layer or a `NEXT_PUBLIC_` variable.

| Variable | Secret | Required by | Used by | Purpose |
|---|---|---|---|---|
| `NODE_ENV` | no | - | web | production for builds and images. |
| `NEXT_RUNTIME` | no | - | web | Set by Next.js itself (nodejs \| edge); read by instrumentation. Do not set. |
| `NEXT_PUBLIC_SUPABASE_URL` | no | web | web | Supabase API URL the browser and the server use (public by design). |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | no | web | web | Supabase publishable (anon) key; public by design, RLS protects data. |
| `NEXT_PUBLIC_APP_URL` | no | - | web | Fallback origin for sign-up confirmation links. |
| `PUBLIC_APP_URL` | no | web | web, worker | Public base URL of the web app (pay/opt-out links, CSRF origin). https in production. |
| `WEBHOOKS_PUBLIC_URL` | no | - | web | Public base URL of the webhook runtime, if different from PUBLIC_APP_URL. |
| `SUPABASE_URL` | no | web | web, worker, cli, test | Supabase API URL for server-side code. |
| `SUPABASE_SERVICE_ROLE_KEY` | yes | web | web, worker, cli, test | Service-role key: server only (Storage signed URLs, staging the API import). Never NEXT_PUBLIC_. |
| `SUPABASE_SECRET_KEY` | yes | - | web | Alternative name for the server key (newer Supabase key format). |
| `SUPABASE_DB_URL` | yes | web | web, cli, test | Direct Postgres URL for the web server trusted pipelines (contains the password). |
| `DATABASE_URL` | yes | - | web | Fallback for SUPABASE_DB_URL in the web server. |
| `WORKER_DATABASE_URL` | yes | worker, webhooks, processor | worker, webhooks, processor, cli, demo | Direct Postgres URL for the worker, processor, webhook runtime and CLIs. Without it they use the LOCAL stack. |
| `SUPABASE_ANON_KEY` | no | - | test | Local anon key for integration tests (read from `supabase status` when unset). |
| `SMTP_HOST` | no | - | worker, web | Default SMTP host (a tenant account can override when SMTP_ALLOW_TENANT_HOST=true). |
| `SMTP_PORT` | no | - | worker, web | Default SMTP port. |
| `SMTP_SECURE` | no | - | worker, web | true for implicit TLS. |
| `SMTP_PASSWORD` | yes | - | worker, cli | Operator SMTP password for SMTP_HOST/SMTP_USER. Used only when a tenant saved no SMTP password of its own; never sent to a tenant-chosen host. |
| `SMTP_USER` | no | - | worker, web | Default SMTP user. Its password: SMTP_PASSWORD (operator) or the tenant one saved in Settings (Vault), which wins. |
| `SMTP_ALLOW_TENANT_HOST` | no | - | worker, web | Let tenant channel config choose the SMTP host. |
| `WHATSAPP_GRAPH_VERSION` | no | - | worker, web | Meta Graph API version; unset = no WhatsApp sending. |
| `WHATSAPP_APP_SECRET` | yes | - | webhooks | Meta app secret for webhook signatures; unset = WhatsApp webhook disabled. |
| `WHATSAPP_VERIFY_TOKEN` | yes | - | webhooks | Meta webhook verification token. |
| `PAYMENTS_WEBHOOKS` | no | - | webhooks | true = serve /webhooks/payments/<token>. |
| `PAYMENTS_ALLOW_FAKE` | no | - | worker, web, webhooks, demo, test | TESTS AND DEMO ONLY: enables the FakeGateway for test-mode accounts. Never set in production. |
| `TRUST_PROXY_HOPS` | no | - | web | How many trusted proxies append X-Forwarded-For (0 = do not trust it). |
| `PORT` | no | - | webhooks | Webhook runtime port. |
| `CLASSIFIER` | no | - | processor | anthropic or openai = classify replies with that provider model; unset = every reply becomes a human task. |
| `CLASSIFIER_MODEL` | no | - | processor | Model id of the chosen provider (required when CLASSIFIER is set). |
| `CLASSIFIER_TIMEOUT_MS` | no | - | processor | Classifier call timeout. |
| `CLASSIFIER_FALLBACKS` | no | - | processor | false = no model fallback (Anthropic only). |
| `ANTHROPIC_API_KEY` | yes | - | processor, worker, smoke | Read by the Anthropic SDK when CLASSIFIER or PROOF_EXTRACTION is anthropic. |
| `OPENAI_API_KEY` | yes | - | processor, worker | Read by the OpenAI SDK when CLASSIFIER or PROOF_EXTRACTION is openai. |
| `PROOF_EXTRACTION` | no | - | worker | anthropic or openai = AI hints on proof images (tenants must also opt in). |
| `PROOF_EXTRACTION_MODEL` | no | - | worker | Model id for proof hints. |
| `PROOF_EXTRACTION_FALLBACKS` | no | - | worker | false = no model fallback (Anthropic only). |
| `NEXT_DIST_DIR` | no | - | test | Build folder (the e2e build uses .next-e2e). |
| `SENTRY_DSN` | yes | - | - | Reserved: no error-reporting vendor is wired (ErrorReporter is a no-op by default). |
| `ALERT_STALE_SECONDS` | no | - | cli | Watchdog: a heartbeat older than this is stale. |
| `OPS_ALERT_EMAIL` | no | - | cli | Watchdog: where system findings are emailed (SMTP defaults). Unset = exit code and JSON only. |
| `OPS_ALERT_FROM` | no | - | cli | Watchdog: sender address for ops alerts. |
| `NEXT_OUTPUT` | no | - | web | Build-time only: `standalone` makes next build emit the traced server the web image runs (set by the Dockerfile). |
| `DUELOOP_SERVICE` | no | - | worker, webhooks, processor | Which service a services-image container runs (worker \| processor \| webhooks); picks the container healthcheck. |
| `HEALTH_MAX_AGE` | no | - | worker, processor | Container healthcheck: a heartbeat older than this many seconds is unhealthy (default 300). |
| `DEMO_WEB_PORT` | no | - | demo | pnpm demo: port of the demo web app (default 3000). |
| `DEMO_WEBHOOKS_PORT` | no | - | demo | pnpm demo: port of the demo webhooks service (default 8787). |
| `DEMO_RECORD` | no | - | demo, test | Set to 1 by pnpm demo:record: the e2e demo records video and keeps page DOMs for the leak check. |
| `DEMO_RECORD_DOM` | no | - | demo, test | Set by pnpm demo:record: where the e2e demo writes the page DOMs it showed. |
| `DEMO_MODE` | no | - | demo | Set by `pnpm demo` only; demo:control refuses without it. |
| `DEMO_NOW` | no | - | demo | Demo clock passed to child processes. |
| `NOW_ISO` | no | - | demo | Demo/script clock. |
| `TENANT_ID` | no | - | demo, smoke | Tenant for scripts. |
| `SEND_LOG` | no | - | test | Test harness log file. |
| `APPLY_LOG` | no | - | test | Test harness log file. |
| `MAILPIT_URL` | no | - | demo, test | Local mail catcher API. |
| `WEBHOOK_URL` | no | - | smoke | Smoke test target. |
| `WEBHOOK_SMOKE` | no | - | smoke | 1 = run the live webhook smoke test. |
| `WHATSAPP_SMOKE` | no | - | smoke | 1 = run the live WhatsApp smoke test. |
| `WHATSAPP_TOKEN` | yes | - | smoke | WhatsApp smoke test access token. |
| `WHATSAPP_PHONE_NUMBER_ID` | no | - | smoke | WhatsApp smoke test sender. |
| `WHATSAPP_SMOKE_TO` | no | - | smoke | WhatsApp smoke recipient (E.164). |
| `WHATSAPP_SMOKE_TEMPLATE` | no | - | smoke | Approved template for the smoke test. |
| `WHATSAPP_SMOKE_LANGUAGE` | no | - | smoke | Template language for the smoke test. |
| `STRIPE_SMOKE` | no | - | smoke | 1 = run the Stripe test-mode smoke test. |
| `STRIPE_TEST_API_KEY` | yes | - | smoke | Stripe TEST-mode restricted key for the smoke test (never live). |
| `EVAL_LIVE` | no | - | smoke | 1 = run the paid live classifier evaluation. |
| `PROOF_EVAL` | no | - | smoke | 1 = run the paid live proof evaluation. |
| `PROOF_EVAL_DIR` | no | - | smoke | Folder of labelled proof images for the live evaluation. |
